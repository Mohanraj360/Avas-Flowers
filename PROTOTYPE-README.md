# Petal & Parcel — Independent Avas Flowers Concept Redesign

A deployable Next.js concept prototype for an unsolicited business pitch. The design direction combines premium floral imagery with conversion-focused UX.

## Important disclosure
- This is an independent concept and is not affiliated with, commissioned by, or endorsed by Avas Flowers.
- Product names, prices, reviews/rating treatments, delivery states, order IDs, and tracking details are illustrative demo content.
- No Avas Flowers APIs, private systems, customer accounts, payments, or fulfillment systems are connected.
- The supplied review dataset is a sample of 346 records spanning June 2018 through April 2024. Categories overlap and are not market-wide complaint rates.
- External Unsplash image URLs are used as visual placeholders; verify licensing/usage terms and replace with properly licensed imagery before public commercial use.

## Run locally
Requires Node.js 18.17+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build
```bash
npm run build
npm run start
```

## Deploy to Vercel
1. Extract this project or push the project folder to a new GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Next.js. No environment variables are required for the demo.
4. Deploy.

## Included interactions
- Homepage and category filtering/search
- Product detail and size selection concept
- Add/remove/update cart quantities
- Itemized pricing, sample service/delivery fees, promo-code preview
- Delivery details and payment step UI (no real payment processing)
- Demo order confirmation
- Example order tracking timeline
- Support request preview
- Review research/methodology page

## Suggested next step for a real business pitch
Present this as a clickable concept, then run 5–8 usability tests and propose an A/B test plan. Do not claim measured conversion or satisfaction improvements until validated with real data.
